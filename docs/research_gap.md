# Research gap

Based on `docs/literature_review.md` (partial -- 2 of 9 topic areas verified).

## What is already established and should not be re-claimed as novel

1. Status is relational/granted, not an attribute the challenger simply possesses
   (duque2018recognizing).
2. Resource-recognition gaps are normal and need case-level explanation, not a single lag
   statistic (roren2019grading) -- this directly supports the brief's rejection of the legacy
   project's aggregate "recognition lag" variable.
3. Status *deficits* (gap between material rank and recognized rank), not status levels, are the
   behaviorally consequential quantity, and reference groups are local ("status communities"), not
   global (renshon2016status, renshon2017fighting).
4. A named, applied mechanism for "a state that struggled for recognition later reproduces
   hierarchy toward a new challenger" already exists in the East Asian context specifically
   (kim2024status, "stigma shifting") -- this project's M5 is an extension, not an invention.
5. Public (not just elite) political support responds to status-loss expectations
   (powers2023international), and the EAI/Genron survey series is an actively used, peer-reviewed
   source for status-perception items in exactly the Korea-Japan dyad this project needs
   (kim2025geopolitics).

## What is NOT yet established (the actual gap, pending full literature coverage)

1. **Timing.** No verified source estimates *when* a peer-recognition transition occurs relative
   to a material-parity date for a specific dyad. The turning-point framework (T1-T4) is this
   project's proposed contribution; it is not yet shown to be redundant with existing work, but
   the literature search is too incomplete (2/9 topic areas) to claim this with confidence.
2. **Cross-domain structure.** Whether economic, political, cultural, and social recognition move
   together or independently is, per the brief, an open construct-validity question this project
   must establish empirically rather than assume.
3. **Mechanism discrimination.** No source found distinguishes M1-M5 empirically within a single
   design; most status literature tests one mechanism (usually M1 or M2) in isolation.
4. **A genuinely East-Asia-specific status-hierarchy literature** (as opposed to developmental-
   state institutional economics) was not located in this pass -- this may be because it does not
   exist in the form the brief imagines, or because the search queries used were insufficient. Not
   resolved; see `docs/literature_review.md` Section 3 for the next queries.

## Consequence for scope

Given (3) and (4) above are unresolved, any claim in this repository's outputs that the project
"shows no prior work addresses X" is NOT currently warranted and should not be made in any
downstream report until the remaining 7 literature topic areas are searched. The
`outputs/reports/research_overhaul_report.md` for this pass states this explicitly as a
methodological risk.
